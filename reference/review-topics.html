2. Gateway: yes or no

Needed: on-premises SQL, on-premises files, SSAS live, private network (VNet gateway).

Not needed: Azure SQL (public), SharePoint Online, OneDrive for work, web sources.

3. Storage-mode chooser

  • Minutes-fresh: DirectQuery; if the data is in a Fabric lakehouse, Direct Lake.
  • Existing published model: live connection.
  • Real-time fact plus fast history: composite, shared dimensions Dual.
  • Files (Excel, CSV) and everything else: Import. Refresh: 8/day Pro, 48/day Premium or Fabric; automatic page refresh needs DirectQuery, min. 30 min in shared capacity.

5. The 15 top traps

#Wrong beliefRight rule
T01Two RLS roles give an intersectionRoles are additive (union). Put both filters in one role for AND
T07Contributor can publish the app and add usersThat needs Member. Contributor edits content only
T12Cloud sources need a gatewayOnly on-prem or private-network sources need one
T15Subscriptions fire on thresholdsAlerts fire on thresholds (card/KPI/gauge tiles). Subscriptions run on a schedule
T17Import can show data within minutesUse DirectQuery for near-real-time
T21Report or DAX filters reduce imported rowsFilter in Power Query (folding) or a SQL WHERE
T23Append adds columnsAppend stacks rows. Merge adds columns
T26A text timestamp converts straight to DateSplit, extract or use Column From Examples first
T31Hiding a column shrinks the modelRemove it in Power Query
T34Row context filters related tablesIt doesn't. You need context transition (CALCULATE / a measure ref) or RELATEDTABLE
T35CALCULATE(…, Year=2023) blanks other yearsIt replaces the filter, so 2023 repeats on every row. KEEPFILTERS intersects
T37PREVIOUSYEAR = same month last yearUse SAMEPERIODLASTYEAR / DATEADD(-1, YEAR)
T41Average or constant line = medianUse a median line or a 50% percentile line
T42Decomposition tree ranks driversKey influencers ranks drivers. Decomposition tree is for ad hoc drill
T44Report theme recolours dashboard tilesUse a dashboard theme
