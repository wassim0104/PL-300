DAX patterns

Thirty-five exam-level patterns you can copy: an ID, a name, the code, when to use it, and the lesson that explains it.

Table and column names are examples: Sales (fact), Product, Region, 'Date' (marked date table). Each block is a measure unless the tag says otherwise. Spaces inside parentheses follow the DAX formatting convention and are optional.

  • DATEADD ( 'Date'[Date], -30, DAY ) as a rolling window
    DATEADD shifts the current dates back; it returns a shifted copy, not a 30-day span. Use DATESINPERIOD (P23).
  • LASTDATE ( ... ) - 365 for last year
    LASTDATE returns a one-row table, not a number. Use SAMEPERIODLASTYEAR or DATEADD (P19, P21).
  • A bare column in a measure, such as Sales[Amount]
    A measure has no row context, so a column needs an aggregator: SUM, MAX, SELECTEDVALUE, or an iterator (P01, P11).
  • MAXX ( Dim, SUMX ( Fact, ... ) ) without CALCULATE
    The row context of Dim does not filter Fact, so every row returns the same total. Wrap in CALCULATE or call a measure (P12).
  • A ratio as a calculated column
    It is stored per row and does not re-evaluate in a visual, so totals are wrong (average of ratios). Use a measure with DIVIDE (P02).

Basics, ratios and filters

P01

Base sum

Measure
Total Sales = SUM ( Sales[Amount] )

Use when: The explicit measure every other measure builds on. Lesson 0016

P02

Ratio

Measure
Margin % = DIVIDE ( [Profit], [Total Sales] )

Use when: Any ratio. DIVIDE returns BLANK instead of an error on divide by zero. Lesson 0017

P03

Fixed filter

Measure
Sales West =
CALCULATE ( [Total Sales], Region[Name] = "West" )

Use when: Pin one column to a value. It replaces any filter on Region[Name]. Lesson 0017

P04

Intersecting filter

Measure
Sales West (slicer-aware) =
CALCULATE ( [Total Sales], KEEPFILTERS ( Region[Name] = "West" ) )

Use when: Same filter, but it intersects with the slicer instead of overriding it. Lesson 0017

P05

% of grand total

Measure
% of Total =
DIVIDE (
    [Total Sales],
    CALCULATE ( [Total Sales], ALL ( Product[Category] ) )
)

Use when: Denominator ignores slicers on Category. Use ALL ( Product ) to ignore every Product column. Lesson 0017

P06

% of visible total

Measure
% of Visible =
DIVIDE (
    [Total Sales],
    CALCULATE ( [Total Sales], ALLSELECTED ( Product[Category] ) )
)

Use when: Denominator keeps slicer, page and report filters; removes only the visual's own filter. Lesson 0017

P07

Column-vs-column filter

Measure
Late Orders =
CALCULATE (
    COUNTROWS ( Orders ),
    FILTER ( Orders, Orders[Shipped] > Orders[Required] )
)

Use when: Comparing two columns in the same row needs FILTER; a simple Boolean filter can reference only one column. Lesson 0017

P08

Variables

Measure
Sales YoY % =
VAR PY = [Sales PY]
RETURN
    DIVIDE ( [Total Sales] - PY, PY )

Use when: Evaluate once, reuse, and make the formula readable. VAR is evaluated where it is defined. Lesson 0017

Counting, iterators and ranking

P09

Distinct count

Measure
Orders = DISTINCTCOUNT ( Sales[OrderID] )

Use when: Count unique values in a column (orders, customers). Lesson 0018

P10

Row count

Measure
Transactions = COUNTROWS ( Sales )

Use when: Count rows of a table, for example fact rows or filtered rows. Lesson 0018

P11

Row-level sum

Measure
Revenue = SUMX ( Sales, Sales[Qty] * Sales[Price] )

Use when: Multiply per row, then add. SUM cannot multiply two columns. Lesson 0018

P12

Max over members

Measure
Best Product Sales =
MAXX ( VALUES ( Product[Name] ), [Total Sales] )

Use when: Best of a measure across members. The measure reference triggers context transition per row. Lesson 0018

P13

Average per day

Measure
Avg Daily Sales =
AVERAGEX ( VALUES ( 'Date'[Date] ), [Total Sales] )

Use when: Average of a daily total; avoids averaging individual transactions. Lesson 0018

P14

Rank

Measure
Product Rank =
RANKX ( ALL ( Product[Name] ), [Total Sales], , DESC, DENSE )

Use when: Rank among all products, ignoring the visual's own filter. DENSE leaves no gaps after ties. Lesson 0018

P15

Top N inside CALCULATE

Measure
Top 3 Sales =
CALCULATE (
    [Total Sales],
    TOPN ( 3, VALUES ( Product[Name] ), [Total Sales], DESC )
)

Use when: Total of the top N members; TOPN acts as a filter table. Lesson 0018

P16

Filter on positive values

Measure
Positive Sales =
SUMX ( FILTER ( Sales, Sales[Amount] > 0 ), Sales[Amount] )

Use when: Aggregate only the rows that meet a row-level condition. Lesson 0018

P17

Related lookup

Calc. column
Category = RELATED ( Product[Category] )

Use when: Calculated column on the many side that pulls a value from the one side. Lesson 0018

Time intelligence

P18

Year to date

Measure
Sales YTD = TOTALYTD ( [Total Sales], 'Date'[Date] )

Use when: Running total from 1 January. Needs a marked date table. Lesson 0019

P19

Prior year

Measure
Sales PY =
CALCULATE ( [Total Sales], SAMEPERIODLASTYEAR ( 'Date'[Date] ) )

Use when: Same dates one year earlier. Lesson 0019

P20

Prior-year YTD

Measure
Sales YTD PY =
CALCULATE ( [Sales YTD], SAMEPERIODLASTYEAR ( 'Date'[Date] ) )

Use when: Compare YTD with the same span last year. Lesson 0019

P21

Previous quarter (shift)

Measure
Sales PQ =
CALCULATE ( [Total Sales], DATEADD ( 'Date'[Date], -1, QUARTER ) )

Use when: Shift the current dates by any interval. DATEADD shifts; it does not build a window. Lesson 0019

P22

YoY %

Measure
Sales YoY % =
DIVIDE ( [Total Sales] - [Sales PY], [Sales PY] )

Use when: Growth against prior year. Lesson 0019

P23

Rolling 30 days

Measure
Sales Last 30 Days =
CALCULATE (
    [Total Sales],
    DATESINPERIOD ( 'Date'[Date], MAX ( 'Date'[Date] ), -30, DAY )
)

Use when: A moving window that ends on the last visible date. Lesson 0019

P24

Rolling 3-month average

Measure
Sales 3M Avg =
CALCULATE (
    AVERAGEX ( VALUES ( 'Date'[Month] ), [Total Sales] ),
    DATESINPERIOD ( 'Date'[Date], MAX ( 'Date'[Date] ), -3, MONTH )
)

Use when: Average of monthly totals across a 3-month window. 'Month' must identify a unique month (for example year-month). Lesson 0019

Balances and relationships

P25

Closing balance

Measure
Closing Balance =
CALCULATE ( SUM ( Bal[Amount] ), LASTDATE ( 'Date'[Date] ) )

Use when: Semi-additive: take the value on the last date in context, never sum over time. Lesson 0020

P26

Last non-blank balance

Measure
Last Units =
CALCULATE (
    SUM ( Inv[Units] ),
    LASTNONBLANK ( 'Date'[Date], CALCULATE ( SUM ( Inv[Units] ) ) )
)

Use when: Same, when the last date may have no row (inventory, headcount). Lesson 0020

P27

Inactive relationship

Measure
Sales by Ship Date =
CALCULATE (
    [Total Sales],
    USERELATIONSHIP ( Sales[ShipDate], 'Date'[Date] )
)

Use when: Role-playing date: activate the inactive relationship for one measure. Lesson 0014

Tables, columns and other objects

P28

Date table

Calc. table
Date =
CALENDAR (
    DATE ( YEAR ( TODAY () ) - 9, 1, 1 ),
    DATE ( YEAR ( TODAY () ), 12, 31 )
)

Use when: Calculated table for a common date table. Mark it as the date table afterwards. Lesson 0014

P29

Band column

Calc. column
Size Band =
SWITCH (
    TRUE (),
    Sales[Amount] < 100, "Small",
    Sales[Amount] < 1000, "Medium",
    "Large"
)

Use when: Bucket rows with ordered conditions; the first true branch wins. Lesson 0016

P30

Text label column

Calc. column
Month Label = FORMAT ( 'Date'[Date], "MMM YYYY" )

Use when: A readable label. Pair it with Sort by column or it sorts alphabetically. Lesson 0014

P31

Number series table

Calc. table
Offsets = GENERATESERIES ( -100, 100, 1 )

Use when: Calculated table of numbers for a what-if or disconnected slicer. Lesson 0016

P32

Grouped table

Calc. table
Year Quarter =
SUMMARIZE ( 'Date', 'Date'[Year], 'Date'[Quarter] )

Use when: Calculated table of distinct combinations. Lesson 0016

P33

Hierarchy depth

Calc. column
Depth =
PATHLENGTH ( PATH ( Emp[EmployeeID], Emp[ManagerID] ) )

Use when: Levels in a parent-child hierarchy (calculated column). Lesson 0016

P34

Calculation item

Calc. item
YTD =
CALCULATE ( SELECTEDMEASURE (), DATESYTD ( 'Date'[Date] ) )

Use when: One item that rewrites any measure in the group. Lesson 0021

P35

Dynamic RLS rule

RLS filter
[Email] = USERPRINCIPALNAME ()

Use when: Table filter expression on a role; each user sees only rows with their own sign-in name. Lesson 0036
