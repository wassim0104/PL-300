Lesson 0005

Profile data before you transform it

PrepareAbout 15 minSkill: pick the profiling tool

After this lesson you can pick the profiling tool that answers a question (empty %, distinct vs unique, statistics) and know its row scope.

Why this matters for the exam

Profiling questions are short and precise: which tool, what does the number mean, over how many rows. They are among the cheapest marks in Prepare once distinct vs unique and the 1,000-row default are fixed in your head.Data profiling tools.

Recall first

Which Power Query feature changes the server for every query at once?

Show answer

A Power Query parameter in the Source step, or Data source settings, Change Source.

Core idea

ToolAnswers
Column quality% Valid, % Error, % Empty
Column distributionHistogram, distinct count (different values) and unique count (values that occur exactly once)
Column profileCount, error, empty, distinct, unique, min, max, average, standard deviation, zeros, NaN, plus a value distribution you can group, for example by text length

For [A, A, B, C]: distinct = 3, unique = 2.

By default profiling uses the top 1,000 rows. Switch the status bar to "Column profiling based on entire data set" for full accuracy. Table.Profile(table) returns the statistics as a table you can load into the model for end users.Power Query M reference. Profiling in the editor adds nothing to the model; a DAX calculated column that counts lengths does.

Practical example

A 2-million-row Customer table shows Email as 0% empty.

  1. The status bar says "based on top 1,000 rows".
  2. Switch to the entire data set.
  3. Column quality now shows 3% empty.
Table.Profile(Customer)

The early rows were simply complete. The fix for the empties comes in lesson 0006.

Traps

Wrong belief: Distinct and unique mean the same. Correct rule: distinct counts different values; unique counts values appearing once.

Wrong belief: Profile stats cover the whole table. Correct rule: the default scope is the top 1,000 rows.

Wrong belief: A calculated column is a fine one-off profile. Correct rule: it grows the model; use the editor tools.
