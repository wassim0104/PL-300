Visuals chooser

Start from the need, find the visual or feature, and see which look-alike to avoid. Exam questions usually offer the “avoid” column as a distractor.

KPI vs gauge. Trend against a target: KPI. One value against min, max and target: gauge.

Key influencers vs decomposition tree. Which factors drive a metric: key influencers. Manual, step-by-step root cause: decomposition tree.

Drill down vs drillthrough vs tooltip. Deeper level in place; a detail page for the clicked value; a peek on hover.
