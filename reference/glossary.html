Glossary

The canonical words used in every lesson: 126 terms, one line each. The L-number opens the lesson that teaches the term. “Semantic model” replaces the old word “dataset”.

A B C D E F G H I K L M O P Q R S T U V W

A

Admin (workspace)
Role with full control, including deleting the workspace and managing all roles. L0032
Aggregation table
A pre-summarised table that answers high-level queries instead of a large detail table. L0022
ALL
DAX function that removes filters from a table or columns, ignoring slicers. L0017
ALLSELECTED
Removes filters inside the visual but keeps outer slicer, page and report filters. L0017
Alt text
Text description of a visual read by screen readers; can be driven by a measure. L0028
Analytics pane
Pane that adds reference lines, forecast, error bars and trend lines to visuals. L0030
Analyze in Excel
Explore a semantic model in Excel PivotTables; needs Build permission. L0032
Anomaly detection
Line-chart feature that flags unexpected values on a date axis. L0030
App
Read-only package of selected workspace items published to audiences. L0033
Append
Power Query operation that stacks rows of tables with the same columns. L0008
Apply security filter in both directions
Relationship option letting RLS filters flow both ways. L0036
Assume referential integrity
DirectQuery relationship option that allows inner joins. L0013
Audience (app)
A group of app users who see a chosen subset of app content. L0033
Auto date/time
Setting that creates a hidden date table per date column. L0014
Automatic page refresh
Report-page refresh on a fixed interval or change detection for DirectQuery. L0029

B

Bidirectional filter (Both)
Cross-filter direction where both related tables filter each other. L0013
Bin
Grouping of numbers or dates into equal-sized ranges. L0030
Bookmark
Saved page state: filters (Data), visibility (Display), current page. L0027
Build permission
Item permission to create content on a semantic model, use Analyze in Excel and XMLA. L0032

C

CALCULATE
DAX function that evaluates an expression in a modified filter context. L0017
Calculated column
DAX column computed row by row at refresh and stored. L0016
Calculated table
Table created with a DAX expression at refresh. L0016
Calculation group
Set of calculation items that rewrite any measure using SELECTEDMEASURE(). L0021
Card
Visual showing a single value. L0023
Cardinality (column)
Number of distinct values in a column; high cardinality compresses poorly. L0022
Cardinality (relationship)
One-to-one, one-to-many or many-to-many matching of keys. L0013
Certified
Highest endorsement, granted by admin-authorised reviewers. L0033
Column distribution
Profiling view showing distinct and unique counts with a histogram. L0005
Column From Examples
Power Query feature that creates a column from sample outputs. L0007
Column profile
Profiling view with full column statistics and value distribution. L0005
Column quality
Profiling view showing % valid, error and empty. L0005
Composite model
Model mixing storage modes or sources. L0003
Conditional formatting
Formatting driven by values via rules, gradient, field value, data bars or icons. L0024
Context transition
Conversion of row context into filter context by CALCULATE or a measure reference. L0018
Contributor
Workspace role that creates and edits content but cannot manage users or publish apps. L0032
Copilot
Generative AI assistant for report pages, narratives and model summaries; needs paid capacity. L0031
Cross-filter direction
Direction in which a relationship propagates filters (Single or Both). L0013

D

Dashboard
Single-page canvas of pinned tiles, created in the service. L0034
Data alert
Notification when a card, KPI or gauge tile crosses a threshold. L0034
Data category
Column property such as City, Country or Image URL that changes how values are used. L0015
Data source settings
Dialog to change source paths, credentials and privacy levels. L0004
Dataflow
Power Query in the service that produces reusable tables for many models. L0011
DAX
Data Analysis Expressions, the formula language for measures, columns and tables. L0016
DAX query view
Desktop view for running and tuning DAX EVALUATE queries. L0022
Decomposition tree
AI visual for ad hoc drill-down of a measure across dimensions. L0031
Deployment pipeline
Tool that moves content across development, test and production stages. L0033
Dimension table
Table of descriptive attributes with a unique key used to filter facts. L0012
Direct Lake
Fabric storage mode reading Delta tables in OneLake into memory without import refresh. L0003
DirectQuery
Storage mode that queries the source at view time without storing data. L0003
DISTINCTCOUNT
Counts distinct values in a column. L0018
DIVIDE
Safe division that returns BLANK or an alternate result on divide-by-zero. L0017
Drill down
Moving to a lower hierarchy level within the same visual. L0026
Drillthrough
Navigating to a target page filtered by the selected value. L0026
Dual
Storage mode where a table acts as Import or DirectQuery per query. L0003
Dynamic RLS
RLS whose filter depends on the signed-in user, e.g. USERPRINCIPALNAME(). L0036

E

Enable load
Query option that controls whether a query loads into the model. L0011
Endorsement
Promoted or Certified label signalling trusted content. L0033
Error bars
Analytics feature showing upper and lower bounds around values. L0030
Explain by / Expand by
Key influencers wells for candidate factors / analysis grain. L0031
Explicit measure
Measure written in DAX, as opposed to an implicit one. L0016
Export data setting
Report/tenant setting: none, summarized, or summarized and underlying. L0029

F

Fact table
Table of events with numeric values and foreign keys. L0012
Featured table
Table exposed as an Excel organisational data type. L0015
Filter context
The set of filters active when a measure is evaluated. L0017
Forecast
Analytics feature projecting a line chart's future values. L0030

G

Gateway (on-premises data gateway)
Bridge letting the service reach on-premises or private data. L0035
Gauge
Visual showing a value against minimum, maximum and target. L0023
Group By
Power Query operation that aggregates rows by one or more columns. L0010

H

Hierarchy
Ordered set of columns enabling drill down. L0015

I

Implicit measure
Aggregation created by dragging a numeric column into a visual. L0016
Import
Storage mode that copies data into the in-memory engine. L0003
Inactive relationship
Relationship not used by default; activated with USERELATIONSHIP. L0014
Incremental refresh
Policy that refreshes only recent partitions using RangeStart/RangeEnd. L0035
Iterator
X function (SUMX, AVERAGEX…) evaluating an expression per row. L0018

K

KEEPFILTERS
Makes a CALCULATE filter intersect with existing filters instead of replacing them. L0017
Key influencers
AI visual ranking factors that drive a metric. L0031
KPI visual
Visual comparing an indicator to a target over a trend axis. L0023

L

Left anti join
Merge returning left rows with no match on the right. L0008
Lineage view
Diagram of dependencies between sources, models, reports and dashboards. L0033
Live connection
Connection to an Analysis Services or published model without local modelling. L0003

M

Mark as date table
Setting that designates the model's date table and date column. L0014
Measure
DAX calculation evaluated at query time in filter context. L0016
Member (workspace)
Role that can add users, publish apps and edit content. L0032
Merge
Power Query join adding columns from a related query. L0008
Mobile layout
Portrait layout of a report page or dashboard for phones. L0028

O

Object-level security (OLS)
Hides tables or columns from specified roles. L0036

P

Paginated report
Pixel-perfect, printable report (.rdl) built with Report Builder. L0023
Parameter (Power Query)
Named value referenced by queries, e.g. server name. L0004
Performance Analyzer
Tool that times each visual's DAX query, display and other work. L0022
Personalize visuals
Setting letting consumers change visuals for themselves. L0029
Pin live page
Pins a whole report page as one interactive dashboard tile. L0034
Privacy level
Private, Organizational or Public setting governing data combination. L0004
Promoted
Endorsement any contributor can apply to signal useful content. L0033

Q

Q&A
Natural-language question feature producing visuals. L0031
Query folding
Translating Power Query steps into a native source query. L0011
Quick measure
Wizard that generates DAX for common calculations. L0020

R

RangeStart / RangeEnd
Reserved DateTime parameters for incremental refresh. L0035
Reference query
Query that starts from another query's output. L0011
Report
Multi-page interactive set of visuals on one semantic model. L0001
Report page tooltip
Page shown on hover, enabled by "Allow use as tooltip". L0026
Role-playing dimension
One dimension used in several roles, e.g. order and ship date. L0014
Row context
The current row during column calculation or iteration. L0018
Row-level security (RLS)
Role-based DAX filters limiting which rows users see. L0036

S

Scheduled refresh
Timed Import refresh in the service (8/day Pro, 48/day capacity). L0035
Selection pane
Pane controlling layer order, visibility, grouping and tab order. L0027
Semantic model
The published model (formerly dataset): data, relationships, measures. L0001
Semi-additive measure
Measure that cannot be summed over time, e.g. balance. L0020
Sensitivity label
Purview label classifying and protecting content, including exports. L0033
Slicer
On-canvas visual filter. L0025
Small multiples
Grid of identical charts split by a category. L0023
Smart narrative
Visual generating dynamic text summaries. L0031
Sort by column
Property sorting one column by another, e.g. month name by number. L0015
Star schema
Facts surrounded by dimension tables. L0012
Storage mode
How a table's data is held: Import, DirectQuery, Dual, Direct Lake. L0003
Subscription
Scheduled email snapshot of a report page or dashboard. L0034
Surrogate key
System-generated integer key for a dimension. L0012
Sync slicers
Sharing a slicer selection and visibility across pages. L0025

T

Tab order
Keyboard and screen-reader navigation order of visuals. L0028
Theme
JSON definition of report colours and styles; dashboards have their own themes. L0024
Time intelligence
DAX functions that shift or accumulate over dates. L0019

U

Unpivot
Turning columns into attribute-value rows. L0009
USERELATIONSHIP
Activates an inactive relationship within CALCULATE. L0014
USERPRINCIPALNAME
Returns the signed-in user's UPN. L0036

V

Viewer
Read-only workspace role; RLS applies. L0032
Visual calculation
DAX calculation defined on and stored in a single visual. L0021

W

Workspace
Container in the service for collaboration on items. L0001
