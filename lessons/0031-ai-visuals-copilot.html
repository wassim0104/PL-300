Lesson 0031

AI visuals and Copilot: key influencers, decomposition tree, Q&A, narratives

Visualize and analyzeAbout 20 min

After this lesson you can pick the AI feature that answers a question (what drives a metric, ad hoc root cause, natural-language question, text summary), fill the key influencers wells correctly, and read its output.

Why this matters for the exam

Questions about AI visuals are a small but dependable slice of the Visualize and analyze domain. They are easy marks once you can match a business question to the right feature, and easy to lose when you swap key influencers and the decomposition tree. Practice questions kept returning to the three wells of key influencers.

Recall first

Which Analytics pane line would you add to show the average of a measure on a chart?

Show answer

The average line (one of the constant, min, max, average, median and percentile lines).

Core idea

Match the question to the feature:

QuestionFeature
What drives this metric, ranked?Key influencers
Why is this number high? Let me dig in, my own way.Decomposition tree
Let me just ask in plain English.Q&A
Give me a text summary that follows my filters.Smart narrative / Copilot narrative

Key influencers has three wells. Key influencers Analyze is the metric. Explain by holds the candidate factors. Expand by holds the grain fields (for example Customer Key) and is used only when Analyze is a measure or summarised field. Output is ranked: categorical metrics read "x times more likely", continuous ones read "+N on average". A Top segments tab groups combinations. See glossary.

For a numeric metric with many distinct values set the analysis type to Continuous. A category appears only if it has enough data points, so a high-average country with few rows may be missing. The dotted line is the average of all other values.

The decomposition tree is ad hoc: you choose the next dimension, in any order, or let an AI split jump to the highest or lowest value. Use it for root-cause exploration such as bounce rate by channel, then device, then country. It does not rank drivers.

Q&A answers natural-language questions, in a visual or in a dashboard box. Improve it with synonyms and linguistic setup, and pin good answers to a dashboard. The smart narrative writes text that updates with filters.

Copilot can also create a report page, suggest content and summarise the semantic model. It needs a paid Fabric capacity (F2 or higher) or Premium (P1+), and the tenant must enable it. Finally, a data point's right-click Analyze offers "Explain the increase/decrease" and "Find where the distribution is different".

Practical example

HR asks which employee attributes make Leaver = Yes more likely.

  1. Add a key influencers visual.
  2. Analyze: Leaver. Explain by: Department, Tenure band, Manager, Overtime.
  3. Read the top bar: for example "Overtime = Yes: 2.1x more likely to leave".

It works because the question is "what increases the likelihood of an outcome", which is exactly what key influencers ranks. If instead Analyze were a measure such as average salary, you would add Employee Key to Expand by so the visual knows the grain, and leave it out of Explain by.

Traps

Wrong: Use the decomposition tree to rank drivers. Right: Ranking is key influencers. The tree is manual exploration.

Wrong: Put the factors in Expand by. Right: Factors go in Explain by. Expand by is only the grain for a measure.

Wrong: A numeric influencer is a ratio. Right: It is an average difference, not a multiple.
