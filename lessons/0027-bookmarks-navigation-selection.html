Lesson 0027

Bookmarks, buttons, navigation and the Selection pane

Visualize and analyzeAbout 18 minSkill: build navigation with bookmarks

After this lesson you can build view switching and page navigation with the fewest bookmarks and objects, and control layering with the Selection pane.

Why this matters for the exam

Bookmark questions test one checkbox (Data) and one design choice (page navigator versus a pile of buttons). The Selection pane also reappears for tab order in accessibility questions.

Recall first

Last lesson: which interaction dims unrelated data and keeps the whole chart visible?

Answer

Highlight. Filter removes it; None ignores the selection. See Lesson 0026.

Core idea

A bookmark saves page state in three parts.Source: Bookmarks.

PropertyStores
DataFilters, slicers, sort state
DisplayVisibility, spotlight
Current pageWhich page is active

A bookmark applies to all visuals or only the selected ones.

Buttons run actions: Back, Bookmark, Drill through, Page navigation, Q&A, Web URL, Apply or Clear all slicers.Source: Buttons and navigators. Two navigators save work. The page navigator (Insert › Buttons › Navigator) makes one button per visible page and updates itself. The bookmark navigator shows the bookmarks in a bookmark group.

The Selection pane has two orders that are easy to confuse. Layer order is stacking (what sits on top). Tab order is reading and keyboard order (Lesson 0028). It also shows or hides objects and groups visuals. Format › General › Properties › Position sets exact x/y and size.

Practical example

A Chart/Table toggle that keeps the user’s slicer choice.

  1. Place both visuals in the same spot.
  2. Selection pane: hide the table, add bookmark Chart. Hide the chart, show the table, add bookmark Table.
  3. On both bookmarks untick Data, keep Display ticked.
  4. Group the bookmarks and insert a bookmark navigator.

Why it works: Display flips visibility, and with Data unticked the bookmark never touches the slicers.

Traps

Wrong: Leave Data ticked on view-toggle bookmarks. Right: the user’s slicers reset on every switch; untick Data.

Wrong: One bookmark button per page is the best navigation. Right: a page navigator updates itself as pages are added or hidden.

Wrong: Layer order sets the reading order. Right: tab order does; layer order is only stacking.
