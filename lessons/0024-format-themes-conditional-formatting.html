Lesson 0024

Themes, conditional formatting and number formats

VisualizeAbout 18 minAfter this lesson you can apply a reusable theme and pick the right conditional-formatting style for a requirement.

Why this matters for the exam

Formatting questions reward knowing which option does what: Rules versus Gradient, report theme versus dashboard theme, data bars with or without numbers. They are short, repeatable scenario questions in the Visualize and analyze the data domain.

Recall first

A KPI compares sales to target by quarter across several years. What should the trend axis use?

A unique period such as Year-Quarter. Quarter alone sums across years.

Core idea

Report theme. A JSON file with colours, fonts and visual defaults, imported in Desktop (View, Themes, Browse) and reusable across reports.Report themes. Customising the current theme affects only that file unless you save and export it.

Dashboard theme (service only) recolours dashboard tiles.Dashboard themes. A report theme does not change existing dashboard tiles. When pinning, choose keep current theme or use destination theme.

Conditional formatting applies to table and matrix cells (background, font colour, data bars, icons, web URL) and to many visual properties such as titles and card values through fx.Conditional table formatting.

StyleUse when
RulesDiscrete thresholds or ranges, for example red below 0, green at 100 or more. A rule can use another field and its aggregation.
GradientA continuous colour scale from low to high.
Field valueA column or measure returns a colour name or hex code.
Data barsMagnitude inside cells. Tick Show bar only to hide numbers.
IconsShape cues, which also help accessibility.

Number formats use custom format strings: 0.00;(0.00) shows two decimals with negatives in parentheses. The colour red comes from conditional formatting, not from the format string.

Practical example

Business context: revenue cells must turn red below 1 M, amber from 1 to 5 M and green above 5 M, with negatives shown in parentheses.

  1. Select the table, open Format, Cell elements, Background colour, then fx.
  2. Format style: Rules. Add three ranges: below 1,000,000 red; 1,000,000 to 5,000,000 amber; above 5,000,000 green.
  3. Set the measure's format string to #,##0;(#,##0).
Status Colour =
SWITCH ( TRUE (), [Revenue] < 1000000, "#C0392B", [Revenue] <= 5000000, "#F39C12", "#27AE60" )

Why it works: Rules gives hard bands. The DAX version is the Field value alternative, handy when many visuals must share the same logic in one measure. A gradient would blur the three bands the requirement asks for.

Traps

Wrong belief: A report theme recolours pinned dashboard tiles.
Correct rule: Existing tiles keep their theme. Use a dashboard theme in the service, or choose the theme option when pinning.

Wrong belief: Gradient suits any colour requirement.
Correct rule: When the requirement states discrete thresholds, use Rules.

Wrong belief: Data bars hide the numbers by default.
Correct rule: Numbers stay visible until you tick Show bar only.
