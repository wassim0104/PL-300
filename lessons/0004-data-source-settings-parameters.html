Lesson 0004

Data source settings, privacy levels and parameters

PrepareAbout 15 minSkill: repoint sources with parameters

After this lesson you can repoint a report to a new server or file and switch environments with a Power Query parameter instead of editing every query.

Why this matters for the exam

Dev/Test/Prod switching, moved files and Formula.Firewall errors are classic Prepare scenarios, and the wrong answers are plausible (what-if parameters, DAX variables). Knowing which tool is for which job is the whole skill.Query parameters.

Core idea

File › Options and settings › Data source settings lists every source. Change Source repoints all queries that use it. Edit Permissions sets credentials and the privacy level.

Privacy levels are Private, Organizational and Public. They decide whether data from one source may be sent to another while combining. Wrong levels cause Formula.Firewall errors or block query folding.Privacy levels and the firewall.

Power Query parameters (Manage Parameters) hold values such as server, database or file path. Reference them in the Source step and change one value to switch environments. They can also be edited in the service under semantic model settings. What-if parameters are a DAX/report feature for slicer-driven scenarios and never change a data source. Incremental refresh needs two DateTime parameters named exactly RangeStart and RangeEnd (lesson 0035).

"Could not find file" after a move means the path is wrong or you lost permission. Fix it with Data source settings, the Source step in the formula bar, or the Advanced Editor.

Practical example

One report must run against Dev, Test and Prod SQL servers. Create parameters ServerName and DbName.

// ServerName = "sql-dev.contoso.com", DbName = "Sales"
let Source = Sql.Database(ServerName, DbName),
    Orders = Source{[Schema="dbo", Item="Orders"]}[Data]
in Orders

Switching to production means changing ServerName once; every query that uses the parameter follows.

Traps

Wrong belief: A what-if parameter or DAX variable can switch servers. Correct rule: only a Power Query parameter feeds a Source step.

Wrong belief: Edit every query by hand. Correct rule: Change Source or one parameter does it.

Wrong belief: Service credentials change the file path. Correct rule: they change only authentication.
