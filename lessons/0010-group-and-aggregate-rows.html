Lesson 0010

Group and aggregate rows

Prepare the dataAbout 15 minSkill: use Group By with the right operation

After this lesson you can use Group By (basic or advanced) with the right operation to reduce granularity or find a top item per group.

Why this matters for the exam

Group By questions test whether you know basic versus advanced, which operation returns what, and how to get the top row per group. They show up in the Prepare the data domain and again as a model-size technique, so learning it once pays twice.

Core idea

Basic Group By allows one grouping column and one aggregation. Advanced allows several of each. Group by.Glossary: Group By. The operations are Sum, Average, Median, Min, Max, Count Rows, Count Distinct Rows and All Rows, which keeps a nested table per group.

NeedDo
Two grouping columnsAdvanced mode
Count each distinct combination onceCount Distinct Rows
Biggest order with its product nameAll Rows, then Table.Max
Fewer rows before loadGroup in Power Query (see lesson 0022)

Max returns only the number, but Table.Max([AllRows], "Units") returns the whole record, which you then expand to get Product and Units. Grouping before load reduces granularity and model size, for example daily impressions instead of event rows. Data reduction techniques.Binning numbers and grouping visual categories are report features (Data pane, New group), not Power Query. See lesson 0030.

Practical example

For each product category, show the product with the most units sold in one order.

  1. Group By Category, operation All Rows (name it AllRows).
  2. Add a custom column with Table.Max.
  3. Expand the record column and keep Product and Units.
Grouped = Table.Group(Sales, {"Category"}, {{"AllRows", each _, type table}}),
Top = Table.AddColumn(Grouped, "TopRow", each Table.Max([AllRows], "Units")),
Expanded = Table.ExpandRecordColumn(Top, "TopRow", {"Product", "Units"})

All Rows preserves every column of each group, so Table.Max can hand back the full winning row. A plain Max aggregation would have lost the product name.

Traps

Wrong belief: “basic Group By handles City and Channel together.” Correct rule: more than one grouping column needs Advanced.

Wrong belief: “Max gives me the top product.” Correct rule: Max returns only the number; use All Rows and Table.Max for the record.

Wrong belief: “Count Rows counts each day once.” Correct rule: duplicates are counted; use Count Distinct Rows.
