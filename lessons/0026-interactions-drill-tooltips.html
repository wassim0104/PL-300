Lesson 0026

Interactions, drill down vs drillthrough, tooltips

Visualize and analyzeAbout 20 minSkill: configure interactions and drilling

After this lesson you can configure how a selection affects other visuals, choose between drill down and drillthrough, and build a report-page tooltip.

Why this matters for the exam

Drill down versus drillthrough is a classic word swap, and the tooltip-page setup is a favourite step-order question. Together they are a dependable source of Visualize marks in the practice material.

Recall first

Last lesson: a Country slicer must filter pages 1 to 3 but hide on pages 2 and 3. Sync and Visible settings?

Answer

Sync on for 1–3; Visible on for page 1 only. See Lesson 0025.

Core idea

Edit interactions

Select the source visual, then Format › Edit interactions. For each target choose Filter (removes unrelated data), Highlight (dims unrelated data, keeps context, shows the share of the total) or None.Source: Change how visuals interact. Maps support cross-filter only. Some visuals cannot highlight.

Drill down or drillthrough

Drill downDrillthrough
MovesDown a hierarchy in the same visualTo a target page
NeedsA hierarchy (Year → Quarter → Month)The field in the target page’s Drillthrough well
ContextVisual-only unless drilling filters othersClicked item; Keep all filters adds slicers

A button with action Drill through passes both the slicer and the selected data point. Page navigation and bookmarks do not.Source: Drillthrough. In a matrix, drill filters reach other visuals only if “Drilling filters other visuals” is on, and visual options set Entire page or Selected visual.

Tooltips

Fields in the Tooltips well add values on hover. For a mini-chart, build a report page tooltip.Source: Tooltips.

  1. New page → Page information → Allow use as tooltip; canvas type Tooltip.
  2. Add the visuals.
  3. On the source visual set Tooltip type = Report page and choose that page.

Practical example

Clicking a product in the bar chart should filter the line chart, dim the column chart and leave the KPI card alone.

Select the bar chart, open Edit interactions, then set: line chart Filter, column chart Highlight, card None. Each target has its own icon row, so one source can behave three ways. The column chart keeps all its bars and dims the unrelated part, so the reader sees the product’s share.

Traps

Wrong: Drill down works without a hierarchy, or the same visual can drillthrough. Right: drill down needs a hierarchy; drillthrough goes to another page.

Wrong: Switch on Allow use as tooltip on the source page. Right: it is set on the tooltip page; the source visual only picks the page.

Wrong: A page-navigation button carries the clicked data point. Right: only a Drill through action does.
