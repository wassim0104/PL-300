Lesson 0006

Fix data types, errors and nulls

PrepareAbout 18 minSkill: choose the cleaning action

After this lesson you can choose the right cleaning action (change type, replace errors, replace values, remove rows) so you keep the rows the requirement needs.

Why this matters for the exam

Cleaning questions hinge on one word in the requirement: "keep all rows", "average", "refresh fails". Read that word and the answer follows. They appear repeatedly in Prepare.Dealing with errors.

Recall first

A column holds A, A, B, C. What are its distinct and unique counts?

Show answer

Distinct 3, unique 2.

Core idea

Set data types on purpose: Whole, Decimal or Fixed decimal number, Date, Date/Time, Text, True/False. Wrong types break relationships, sorting and time intelligence.Data types.

ActionEffect on rows
Replace ErrorsKeeps the row, puts a value where the error was
Remove ErrorsDeletes the rows with errors
Keep ErrorsKeeps only error rows (diagnosis)
Replace ValuesSwaps one value for another, such as null for 0

Think before turning nulls into 0: AVERAGE ignores blanks but counts zeros, so replacing nulls lowers averages. Replace only when null truly means zero.Replace values. Custom-column arithmetic needs compatible types, so convert operands first.

Refresh errors: "column 'X' not found" means the column was renamed or removed at source; "Could not find file" means the file moved or permission was lost. For case differences, Power Query is case-sensitive but the VertiPaq engine is not; normalise with Transform › Format › Uppercase, not with storage mode changes.

Practical example

Discount has a few "N/A" entries that become errors once typed as Decimal. The requirement says keep all rows and use 0.05 for bad values.

  1. Change type to Decimal Number.
  2. Select Discount, Transform › Replace Errors, enter 0.05.
Table.ReplaceErrorValues(Typed, {"Discount", 0.05})
// nulls to 0 (only when null means zero):
Table.ReplaceValue(Orders, null, 0, Replacer.ReplaceValue, {"Order Value"})

Replace Errors keeps every row; Remove Errors would silently drop them.

Traps

Wrong belief: Remove Errors satisfies "keep all rows". Correct rule: it deletes rows; use Replace Errors.

Wrong belief: Nulls to 0 is always safe. Correct rule: it biases averages downward.

Wrong belief: Formatting a column changes its type. Correct rule: formatting is display; type is storage.
