Lesson 0034

Dashboards, data alerts and subscriptions

Manage and secureAbout 18 min

After this lesson you can build a dashboard by pinning the right way, and choose a data alert or a subscription for a notification need.

Why this matters for the exam

"Email me when..." versus "email me every Monday" is a classic exam fork, as is pin visual versus pin live page. Both appeared in practice questions and both are settled by one fact each, which this lesson gives you.

Recall first

A new report page must reach existing app users. What do you do?

Show answer

Update the app. Do not create a new one.

Core idea

Pin visual: one tile per visual, clicking opens the report. The tile keeps the visual's definition from pin time, so if the visual's design changes, pin it again. Tile data follows the model refresh.

Pin live page: the whole page becomes one live, interactive tile that reflects later changes, including added visuals. Other tiles: Q&A answers, video, web content, image, text box.

Data alertSubscription
TriggerA threshold is crossedA schedule (daily, weekly, after refresh)
WhereService, dashboard tile of type card, KPI or gaugeReport page or dashboard
SendsA notificationA snapshot by email
ScopePrivate to its creatorYou can subscribe others if permitted

Data alerts watch one value against a fixed threshold and fire at most about once per hour or per refresh. You cannot set one on a report visual directly, so pin it first. "Price crosses its moving average" is not a fixed threshold, unless a measure reduces it to one value. Subscriptions are about time, not conditions. Glossary: data alert, subscription.Dashboard themes are in lesson 0024 and the dashboard mobile layout in 0028.

Practical example

Facilities want an email when freezer temperature exceeds 4 degrees C.

  1. In the report, add a card showing the latest temperature.
  2. Pin the card to a dashboard.
  3. On the tile choose ... > Manage alerts > Add alert rule, condition Above 4.

Why it works: the card is a single value, the dashboard tile can carry an alert, and the threshold is fixed. A subscription would send mail whether or not the freezer is too warm.

Traps

Wrong: A subscription handles a threshold condition. Right: Subscriptions are time based. Use a data alert.

Wrong: Any tile can have an alert. Right: Only card, KPI and gauge tiles do.

Wrong: Pin visuals one by one to keep a page interactive and in sync. Right: Pin the live page.
