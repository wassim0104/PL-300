Lesson 0028

Design for accessibility and mobile

Visualize and analyzeAbout 18 minSkill: design accessible and mobile reports

After this lesson you can make a report usable by screen-reader, keyboard and colour-vision-deficient users, and build report and dashboard mobile layouts.

Why this matters for the exam

Expect scenario questions: a status table in red and green, a card a screen reader must read, a phone view. Know which layout lives where, because report and dashboard mobile views are separate.

Recall first

Last lesson: you must keep a user’s slicer choice when toggling two bookmarks. Which property do you untick?

Answer

Data. See Lesson 0027.

Core idea

Accessibility

  • Alt text on every meaningful visual. Static text never changes, so for a live value drive alt text from a DAX measure through conditional formatting (fx).Source: Creating accessible reports.
  • Tab order (Selection pane) gives a logical reading order. Hide decorative shapes from it.
  • Never colour alone. Add icons with different shapes, data labels or markers; use accessible theme colours and enough contrast. Swapping red for orange does not help.Source: Accessibility overview.
  • Clear titles, sensible font sizes, and Show as table (Alt+Shift+F11).

Practical example

A status table uses red and green fills only.

  1. Add icon conditional formatting with different shapes (a circle for good, a diamond for bad).
  2. Add a status text column.
  3. Set alt text for the visual.

Why it works: shape and text carry the meaning, so colour is optional. For the screen-reader card, use a measure such as:

Alt Sales = "Total sales is " & FORMAT ( [Total Sales], "#,0" )

Bind it through the alt text fx button so it updates after every refresh.

Traps

Wrong: Static alt text suits a live KPI. Right: it goes stale; bind alt text to a measure.

Wrong: Layer order sets reading order. Right: tab order does.

Wrong: Edit the report mobile view when the phone view of a dashboard is required. Right: use the dashboard’s own Mobile layout in the service.

More in the common mistakes sheet.
