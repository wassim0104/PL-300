Analytics pane, anomalies, grouping and clustering

Visualize and analyzeAbout 20 minSkill: add analytics, groups and clusters

After this lesson you can add the right reference line, forecast, error bars or anomaly detection, and group, bin or cluster data to reveal patterns.

Why this matters for the exam

These questions ask “which feature, which chart type”. A median line, anomaly detection on a date axis, 7-day bins and automatic clusters each came up in practice questions, and each has one right answer.

Core idea

Analytics pane

Reference lines: Constant, Min, Max, Average, Median, Percentile (Median is the 50th percentile), Trend, and X/Y constant lines on scatter.Source: Analytics pane. An average or constant line is not a median.

  • Forecast: line chart with a continuous date axis; set length, confidence interval, seasonality.
  • Error bars: line, bar and column charts, from upper and lower bound fields or measures.
  • Anomaly detection: line chart with a date/time axis and no legend. It marks unexpected points with an expected range and explanations; a higher Sensitivity flags more.Source: Anomaly detection.

Grouping and clustering

ToolUse for
List groupCategories into groups (states → regions)
BinNumbers or dates, by size of bins (7-day) or number of bins
ClustersScatter › … › Automatically find clusters; adds a cluster field

Grouping starts in the Data pane or via a visual’s New group.Sources: Grouping and binning, Scatter charts. On scatter, Play axis animates over time and High-density sampling keeps many points readable. For outliers use a scatter (or a box-plot custom visual); for time-series anomalies use anomaly detection.

Practical example

A bar chart of salaries needs a line that splits employees into above and below the middle.

Select the visual, open the Analytics pane, add a Median line (or a Percentile line at 50%). The line sits where half the values are higher and half lower. An Average line is pulled by large salaries, and a Constant line is just a number you typed, so neither splits the group in half.

Traps

Wrong: An average or constant line shows the median. Right: use the Median line or a 50% percentile.

Wrong: Anomaly detection runs on a column chart or a category axis. Right: it needs a line chart with a date/time axis.

Wrong: Bins work for text categories. Right: bins are for numbers and dates; use list groups for text.
