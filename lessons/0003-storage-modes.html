Lesson 0003

Choose a storage mode: Import, DirectQuery, Dual, Direct Lake

PrepareAbout 20 minSkill: choose a storage mode

After this lesson you can pick the storage mode for each table from freshness, size, source and performance needs, and justify it.

Why this matters for the exam

Storage-mode choices appear in the Prepare domain and come back in Model and Manage questions (refresh, RLS, composite models). The pattern is always the same: match the requirement words to a mode.Storage mode in Power BI Desktop.

Core idea

ModeHow it worksChoose when
ImportCopies data into in-memory VertiPaq. Fastest, all DAX and Power Query. Fresh only as of last refresh (up to 8/day Pro, 48/day Premium or Fabric).Daily or hourly freshness is fine
DirectQueryStores nothing; each visual queries the source. Near real time, slower visuals, some features limited.Minutes-fresh or too large to import. Not for Excel or CSV.
DualActs as Import or DirectQuery per query.Dimensions related to both DirectQuery and Import tables
Direct LakeReads Delta tables in OneLake into memory. Near-Import speed, no import refresh. Some queries fall back to DirectQuery.Data already in a Fabric lakehouse or warehouse

A composite model mixes storage modes, or uses DirectQuery to a published semantic model plus local tables.Composite models. A live connection to Analysis Services or a published model allows no Power Query and no model editing, only report measures; RLS lives in the source model.Report lifecycle.

With DirectQuery and single sign-on, the source database's security applies to the signed-in user; with Import it does not.About DirectQuery; Direct Lake. Automatic page refresh needs DirectQuery, Direct Lake or push sources (lesson 0029).

Practical example

A retailer needs sales visible within 5 minutes, yet historical trend pages must stay fast.

TableModeReason
SalesDirectQueryFive-minute freshness
SalesAgg (monthly)ImportFast trend visuals in memory
Date, CustomerDualRelate to both without limited relationships

Monthly visuals hit SalesAgg in memory; drilling to transactions queries Sales at the source.

Traps

Wrong belief: Import with frequent refresh meets "visible within minutes". Correct rule: scheduled refresh cannot do that; use DirectQuery.

Wrong belief: Shared dimensions can stay Import beside a DirectQuery fact. Correct rule: that creates limited relationships; use Dual.

Wrong belief: An Excel workbook can be DirectQuery. Correct rule: files support Import only.
