Lesson 0029

Personalisation, export settings and automatic page refresh

Visualize and analyzeAbout 15 minSkill: set personalise, export and refresh options

After this lesson you can configure report settings that let consumers adapt visuals, control data export, and refresh a page automatically.

Why this matters for the exam

Three small settings, three favourite traps: page refresh on Import, a 1-minute interval in shared capacity, and blocking export with RLS. Each is one memorised fact worth a mark.

Recall first

Last lesson: where do you edit the phone view of a dashboard?

Answer

In the service: dashboard, Edit, Mobile layout. See Lesson 0028.

Core idea

Personalize visuals. Turn it on in report settings (Desktop: File › Options › Current file › Report settings, or in the service). Consumers can then change visual type, swap measures and dimensions, and change the legend for themselves, and save the result as a personal bookmark. Enable it per report or per visual.Source: Personalize visuals.

Export data. The report setting offers three options, limited by the tenant setting.Source: Export data from visuals.

  • None
  • Summarized data only
  • Summarized and underlying data (underlying also needs Build permission on the model)

One report: that report’s setting. Whole organisation: the tenant admin setting. RLS and model permissions do not stop export of what a user can already see.

Automatic page refresh (Format page › Page refresh) works with DirectQuery sources (and some push or Direct Lake cases), not Import.Source: Automatic page refresh.

TypeRule
Fixed intervalMinimum 30 minutes in shared capacity; shorter in Premium or Fabric, as the admin allows
Change detectionA measure is checked for changes; needs Premium or Fabric

Comments on reports, dashboards, tiles or visuals let consumers discuss content with @mentions.

Practical example

Ops needs a page updated every 5 minutes from Azure SQL.

  1. Model on DirectQuery, workspace on Fabric or Premium capacity.
  2. Format page › Page refresh On, type Fixed interval, 5 minutes.
  3. Confirm the capacity admin minimum is 5 minutes or lower.

Why it works: the refresh re-queries the source; Import data would just redraw the same cache.

Traps

Wrong: Automatic page refresh works on an Import model. Right: it needs DirectQuery.

Wrong: Shared capacity allows a 1-minute interval. Right: the minimum is 30 minutes.

Wrong: RLS or model permissions can block export. Right: use the report export setting, or the tenant setting for everything.

More in the common mistakes sheet.
