# Mission: Microsoft PL-300 — Power BI Data Analyst

## Why
Pass the PL-300 certification exam (score ≥ 700/1000) to earn the Microsoft Certified: Power BI Data Analyst Associate credential, and be able to build, model and secure real Power BI reports with confidence. *(Inferred from the study material provided; confirm or correct with the teacher.)*

## Success looks like
- Score ≥ 80% on two consecutive mock exams built from the question bank, across all four domains.
- Choose the right storage mode (Import / DirectQuery / Dual / Live connection) for a scenario and justify it.
- Write and debug core DAX measures: CALCULATE, filter context vs row context, time intelligence, RELATED/USERELATIONSHIP.
- Shape data in Power Query (merge vs append, unpivot, data types, profiling, query folding).
- Configure RLS, workspace roles, apps, gateways and scheduled/incremental refresh correctly.
- Pick the right visual/feature for an analysis need (decomposition tree, key influencers, drillthrough, bookmarks…).

## Constraints
- Self-study from the PDFs in `pl300/` plus Microsoft Learn; ~6–8 h/week over ~6 weeks (adjustable).
- Practice-dump answers are sometimes wrong: Microsoft documentation wins.

## Out of scope
- Fabric/Data Engineer exams (DP-600/DP-700), Power BI administration beyond PL-300, advanced DAX optimisation beyond exam level.
