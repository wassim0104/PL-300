Lesson 0009

Reshape tables: unpivot, pivot, transpose, JSON

Prepare the dataAbout 20 minSkill: unpivot crosstabs and expand JSON

After this lesson you can turn crosstab or nested data into a tidy long table that a star schema can use.

Why this matters for the exam

Excel-style crosstabs (one column per month or year) and JSON text are classic PL-300 inputs, and they appear in several practice questions. Reports and relationships need one value per row, so unpivoting is often the first step before any modelling.

Recall first

A merge needs the key columns to share what?

Show answer

The same data type. Left anti returns left rows with no match in the right table.

Core idea

Unpivot turns columns into rows (wide to long) and creates Attribute and Value columns; rename them, for example Month and Sales. Unpivot columns. The safest form is Unpivot Other Columns: select the key columns you keep (Product, Region) and unpivot everything else, so new month columns that arrive later are picked up. Unpivot Only Selected Columns fixes the list instead.Glossary: Unpivot.

Pivot is the reverse (long to wide). Pivot columns. Transpose swaps all rows and columns and loses headers, so demote headers first (Use Headers as First Row) and promote them again afterwards.

JSON: parse a text column first with Transform, Parse, JSON, then expand. For a list of records, use To Table, expand the column, then Expand to New Rows for lists and Expand to New Columns for records. JSON connector.

Practical example

An Excel sheet “Budget” has a title row, then headers Department, 2023, 2024, 2025. You need Department, Year, Revenue rows that survive a 2026 column.

Typical order: remove top rows, Use First Row as Headers, select the key column, Unpivot Other Columns, rename, set types.

let Source = Excel.Workbook(File.Contents(Path), null, true){[Item="Budget"]}[Data],
    Promoted = Table.PromoteHeaders(Source),
    Unpivoted = Table.UnpivotOtherColumns(Promoted, {"Department"}, "Year", "Revenue"),
    Typed = Table.TransformColumnTypes(Unpivoted, {{"Year", Int64.Type}, {"Revenue", Currency.Type}})
in Typed

Because Department is the only column named, every year column, including future ones, becomes a row. The result is a tidy fact-style table you can relate to a date dimension.

Traps

Wrong belief: “I select the value columns to unpivot others.” Correct rule: select the key columns you keep (Department); Unpivot Other Columns handles the rest.

Wrong belief: “pivot flattens a crosstab.” Correct rule: pivot goes long to wide; for wide to long use unpivot.

Wrong belief: “I can expand a JSON text column directly.” Correct rule: parse it as JSON first, then expand.
