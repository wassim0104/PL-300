4 domainsPass: 700 / 1000One page

The exam in one paragraph

PL-300 (Microsoft Power BI Data Analyst) measures four skill areas. You need 700 out of 1000 to pass. Questions include case studies, Yes/No series, drag-and-drop and hotspot items. This workspace follows the study guide as updated 20 April 2026: PL-300 study guide.

Question types

TypeHow to handle it
Case studyA scenario with several questions. Read the requirements first, then the data and constraints. Exhibits matter.
Yes/No seriesThe same scenario repeats with a different proposed solution each time. Judge every solution on its own; several can be right, or none.
Drag-and-dropOrder steps or match items to targets. Know the standard sequences, such as the gateway refresh steps and the RLS workflow.
HotspotPick the right value in each drop-down of a code or settings snippet. Know the exact functions and settings (for example Text.StartsWith vs FindText, DATESINPERIOD vs DATEADD).
Single and multiple choiceMulti-select items say how many to pick. Re-read the stem for “least privilege” or “least effort”.

Passing score

700 / 1000 on a scaled score. It is not a straight percentage, so do not count raw answers. Our readiness rule is stricter: two consecutive mock exams at 80% or more (see the study plan; mocks: 1, 2, mixed practice).

Exam-day tips

  • Answer from Microsoft Learn behaviour, not from memory of old forum answers. Current names are semantic model and Microsoft Entra ID.
  • Look for the constraint word: least privilege, least effort, without a gateway, near real time, reduce model size. It usually decides between two plausible options.
  • In Yes/No series, do not let the previous solution bias the next one.
  • Check the question type before you answer: how many options to select, or whether you must order steps.
  • Do not spend a long time on one item. Mark it, move on, and return if the interface allows. Some exam sections may not let you go back, so read the on-screen instructions.
  • Do not learn anything new in the last 12 hours. Use the review-topics sheet and sleep.
  • Check the exam page for the current language, price and policies: PL-300 exam page.
