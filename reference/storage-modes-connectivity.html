Excel and CSV files cannot be DirectQuery sources. A composite model mixes modes, or adds local tables to a published semantic model.

2. Decision flow

  1. Must reports show changes within minutes? Yes: Fabric lakehouse or warehouse data points to Direct Lake, anything else to DirectQuery.
  2. No: does a published semantic model or SSAS model already have the measures? Use a live connection (add local tables for a composite model).
  3. Otherwise: a big real-time fact plus fast history gives a composite model with Dual dimensions. Everything else: Import.

3. Gateway: yes or no

Gateway needed

  • On-premises SQL Server (Import, DirectQuery)
  • On-premises files and shares (Excel, CSV, Folder with a local or network path)
  • SSAS live connection (on-premises)
  • Sources inside a private network or VNet: on-premises gateway, or a VNet data gateway

No gateway

  • Azure SQL Database with public access
  • SharePoint Online and OneDrive for work (Web or SharePoint folder connector)
  • Web sources and other internet-reachable cloud sources
  • Direct Lake (Fabric) and published semantic models in the service

Standard mode gateway: shared, multi-user, supports DirectQuery and live connections. Personal mode: one user, Import only. The server and database names in the PBIX must match the gateway data source. Steps: install and register, add data source with credentials, publish, map the model to the connection, schedule refresh.

A gateway for Azure SQL or SharePoint Online (T12). Scheduled refresh to “keep SSAS or DirectQuery current” (T13): they query the source, so they need a gateway but no refresh. See T12, T13, T17.

4. Refresh facts

  • Scheduled refresh: up to 8 a day on shared capacity (Pro), 48 a day on Premium or Fabric capacity.
  • Inactivity: refresh is paused after two months without anyone opening the report or dashboard. Opening it resumes it.
  • Incremental refresh: create the DateTime parameters RangeStart and RangeEnd, filter the table on them (the filter must fold), then set the policy (archive N years, refresh the last N days). It applies after publishing. It cuts refresh time and gateway transfer. Aggregations do not.
  • Automatic page refresh: DirectQuery (and some push or Direct Lake) sources only, not Import. Fixed interval: minimum 30 minutes in shared capacity; shorter intervals need Premium or Fabric and an admin setting. Change detection needs Premium or Fabric.
  • Dashboard tiles have their own cache refresh. A dashboard has no data refresh of its own.
