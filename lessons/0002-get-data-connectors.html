Lesson 0002

Connect to the right data source

PrepareAbout 18 minSkill: pick a connector

After this lesson you can pick the right connector for a source description, including files in OneDrive/SharePoint and existing published semantic models.

Why this matters for the exam

"Which connector should you use?" is a staple of the Prepare domain, and the answer is nearly always one of a handful of options below. Learn the pairs once and these are quick marks toward your pass.Full list: Data sources for Power BI.

Core idea

Source descriptionConnector
Many files in a local or network folderFolder: lists files with Name, Extension, Date modified, Attributes, Folder Path and a binary Content column
Files in a SharePoint or OneDrive for work siteSharePoint folder: filter on Folder Path or Name, then combine
Items of a SharePoint listSharePoint list (list items, not files in a library)
Power Apps or Dataverse for Teams dataDataverse
A driver exists but no dedicated connectorODBC (DSN or connection string)
A model already published with measuresPower BI semantic models (live connection, no Power Query)
Cloud Azure DevOps Boards / on-premisesAzure DevOps / Azure DevOps Server

Remove the Content column to keep only file metadata; keep it and combine to load the data.Folder connector. An Excel file on OneDrive for work or SharePoint, reached through Web (file URL) or SharePoint folder, refreshes in the service with no gateway. The same file via a local path (Excel Workbook or Folder) needs a gateway.SharePoint folder connector.

Excel files support Import only. Relational sources such as SQL Server and Azure SQL support Import or DirectQuery (next lesson). A live connection to a published semantic model reuses its measures and relationships, which is the least effort when the model exists.Connect to semantic models.

Practical example

Manufacturing keeps 40 monthly Excel files in a SharePoint library next to unrelated HR files.

  1. Get data, SharePoint folder, enter the site URL.
  2. Transform. Filter Folder Path contains /Manufacturing/.
  3. Combine files.
Table.SelectRows(Source, each Text.Contains([Folder Path], "/Manufacturing/"))

Only the 40 relevant files combine, and the report refreshes in the service without a gateway because SharePoint is reachable from the cloud.

Traps

Wrong belief: SharePoint list reads Excel files in a library. Correct rule: it reads list items; use SharePoint folder for files.

Wrong belief: Rebuild the model from raw files. Correct rule: if a published semantic model has the measures, connect to it.

Wrong belief: Keeping Content is harmless. Correct rule: it loads every file's data when you only wanted metadata.
